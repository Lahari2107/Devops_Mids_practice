Step 2: Install NetBeans IDE 21
1. Open your browser.
2. Search for Apache NetBeans IDE 21 download.
3. Download the Windows installer or suitable package.
4. Install NetBeans IDE 21.
5. Open NetBeans.

Step 3: Download Selenium WebDriver
1. Open the Selenium official website: Selenium Downloads.
2. Navigate to the Selenium Client and WebDriver Language Bindings section.
3. Select Java.
4. Download the Selenium Java ZIP file.
5. Extract the downloaded ZIP file into your working directory.

Step 4: Create a Java project in NetBeans
1. Open NetBeans IDE 21.
2. Click File → New Project.
3. Select Java with Ant → Java Application (or the equivalent Java project option available).
4. Click Next.
5. Enter the project name as SeleniumAutomation.
6. Click Finish.

Step 5: Add Selenium JAR files to the project
According to your lab manual:
1. In the Projects panel, expand your project.
2. Locate Libraries.
3. Right-click Libraries.
4. Select Add JAR/Folder.
5. Navigate to the extracted Selenium Java folder.
6. Select all the required JAR files using Ctrl + A.
7. Click Open.

Step 6: Download Microsoft Edge WebDriver
Your lab manual uses EdgeDriver in its Selenium Java program.
1. Open Microsoft Edge.
2. Enter the following in the address bar:
edge://settings/help

3. Note your Microsoft Edge browser version.
4. Open the official Microsoft Edge WebDriver download page.
5. Download the Edge WebDriver matching your browser version and Windows architecture.
6. Extract the downloaded file.
7. Locate msedgedriver.exe.
8. Keep it in your project working directory or another accessible folder.
Example:
SeleniumAutomation/
│
├── src/
│
├── Libraries/
│
└── msedgedriver.exe

Step 7: Create a Selenium Java program
1. In NetBeans, expand Source Packages.
2. Right-click the package.
3. Select New → Java Class.
4. Enter the class name FirstSeleniumPro.
5. Click Finish.

------------------------------------------------
FirstSeleniumPro.java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.edge.EdgeDriver;

public class FirstSeleniumPro {

    public static void main(String[] args) {

        // Initialize Edge WebDriver
        WebDriver driver = new EdgeDriver();

        try {

            // Open Google website
            driver.get("https://www.google.com");

            // Print the title of the page
            System.out.println("Title: " + driver.getTitle());

            // Wait for 60 seconds
            Thread.sleep(60000);

        } catch (Exception e) {

            System.out.println("Error: " + e.getMessage());

        } finally {

            // Close the browser
            driver.quit();
        }
    }
}
------------------------------------------------

Step 8: Run the Selenium program
1. Save the Java file.
2. Right-click FirstSeleniumPro.java.
3. Select Run File (or press Shift + F6).

Step 2: Write the Selenium Java program
VerifyPageTitle.java

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.edge.EdgeDriver;

public class VerifyPageTitle {

    public static void main(String[] args) {

        // Launch Microsoft Edge browser
        WebDriver driver = new EdgeDriver();

        try {

            // Open the target webpage
            driver.get("https://www.google.com");

            // Get the title of the webpage
            String actualTitle = driver.getTitle();

            // Display the page title
            System.out.println("Page Title: " + actualTitle);

            // Expected webpage title
            String expectedTitle = "Google";

            // Verify the page title
            if (actualTitle.equals(expectedTitle)) {

                System.out.println("Test Passed!");
                System.out.println("Page title is correct.");

            } else {

                System.out.println("Test Failed!");
                System.out.println("Page title does not match.");

            }

            // Wait for 10 seconds
            Thread.sleep(10000);

        } catch (Exception e) {

            System.out.println("Error: " + e.getMessage());

        } finally {

            // Close the browser
            driver.quit();
        }
    }
}

Step 3: Execute the program
1. Save the Java file.
2. Right-click VerifyPageTitle.java.
3. Select Run File or press Shift + F6.
